# Website Klinik Fisioterapi Yayasan Sinar Pelangi

## Isi folder
- `index.html` : halaman website utama
- `assets/` : foto fasilitas, materi layanan, dan logo

## Sebelum dipublikasikan
1. Buka `index.html` dan cari `628XXXXXXXXXX`.
2. Ganti dengan nomor WhatsApp klinik, format internasional tanpa tanda +. Contoh `6281234567890`.
3. Ganti teks `[Isi alamat lengkap klinik]`, `[Isi hari dan jam operasional]`, serta kontak lain di bagian footer.
4. Pastikan nama layanan dan tarif masih sesuai dengan daftar resmi klinik.

## Cara upload ke GitHub
1. Buat repository baru, misalnya `fisioterapi-sinar-pelangi`.
2. Upload `index.html` dan seluruh folder `assets` (jangan hanya upload index.html).
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses publikasi, lalu buka alamat website yang diberikan GitHub Pages.

Catatan: website ini adalah website statis HTML/CSS/JavaScript dan tidak memerlukan instalasi atau database.
